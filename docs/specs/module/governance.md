# governance module
Goal: audited access. `createGovernance({audit, query})` wraps a search function so every search records an audit event (actor=principal.userId, action="search", target=query hash, detail=result count) via audit-service before returning, and exposes `verify(tenantId)` and `checkpoint(tenantId)`. Audit failure fails closed (no results returned). Acceptance: every search leaves one verifiable audit row; tamper detected via audit-service; audit store failure blocks results; tenants independent; raw query text never stored (hash only).
