# ingestion module
Goal: connector to index pipeline. `createIngestion({runtime, indexService, connectorFor, tokenFor})` resolves the connector and credential per tenant (unknown tenant: IngestionError UNKNOWN_TENANT), runs connector-runtime runOnce with a sink that calls index-service apply(event); returns {runOnce(tenantId)} with counts {emitted, indexed, failed, failures: {address, error}[], quarantined}. A failing document does not block others, is retried up to maxAttempts then quarantined, and deletes still run. Runs per tenant are serialised. Acceptance: first run indexes all docs, rerun indexes none, modified file reindexes one, index failure is reported in failures and retried, ACL change reindexes, failing doc does not block others, wrong-tenant connector rejected, deleted file tombstones. Requires services/index-service merged first.
