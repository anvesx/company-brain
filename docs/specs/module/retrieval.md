# retrieval module
Goal: one call that wires query-service into mcp-service. `createRetrieval({index, registry, principalFor, transport, port?})` builds createQueryService, adapts its sync search to the async SearchFn (query embedding via injected `embedQuery(text)`), starts startMcpServer, returns {close(), port}. Audit (required): `audit` (@brain/audit-service) and `auditKey` (non-empty master secret) are required deps; missing -> RetrievalError CONFIG at construction. Every search records one row (actor, action="search", target=HMAC(HMAC(auditKey, tenant), trimmed query), detail={count}) before results return; a failed write fails the search closed (safe MCP error, no pointers); failed searches leave no row. Logic is a small duplicate of governance (modules cannot depend on modules). Acceptance: real HTTP MCP client calls `search` end to end against a real in-memory index+registry; ACL-hidden docs never returned; unauthenticated 401; embedQuery failure becomes safe MCP error.
Rules: package modules/NAME, name @brain/NAME, may depend on @brain/* services and features (never apps, never another module). Compose existing packages; build no new core logic. TDD: failing tests first in tests/{unit,integration}. Files <=80 lines, folders <=5 files (README exempt), src/ tests/ README.md in the package plus README in each src subfolder. ESM TypeScript, vitest 5. Copy config shape from services/query-service.
