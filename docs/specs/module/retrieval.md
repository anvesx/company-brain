# retrieval module
Goal: one call that wires query-service into mcp-service. `createRetrieval({index, registry, principalFor, transport, port?})` builds createQueryService, adapts its sync search to the async SearchFn (query embedding via injected `embedQuery(text)`), starts startMcpServer, returns {close(), port}. Acceptance: real HTTP MCP client calls `search` end to end against a real in-memory index+registry; ACL-hidden docs never returned; unauthenticated 401; embedQuery failure becomes safe MCP error.
