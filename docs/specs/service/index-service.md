# index-service
Goal: apply change events to the index. `createIndexService({registry, index, chunk, embed})` exposes `apply(event)`: upsert pointer; if change=="unchanged" do nothing; if updated/created fetch text via injected `fetchText(pointer)` (or use the optional `content: {text, contentHash}` on the upsert event, verified against the pointer's contentHash and the text itself, else `IndexServiceError("HASH_MISMATCH")` before any state change; no `fetchText` call then), chunk it, embed via injected `embed(texts)`, replace the doc's chunks in hybrid-search (remove(docId,tenantId) then add). Deleted event tombstones pointer and removes chunks. Uses @brain/pointer-registry, @brain/chunker, @brain/hybrid-search, @brain/core-types.
Failure rules: on any failure the prior pointer is restored with the intersection of old and new ACL (also written to the index via `updateAcl`), so a revocation is never undone and access never widens; the error is still thrown. If `add` fails and the cleanup `remove` also fails, throw `IndexServiceError("CLEANUP_FAILED")` whose cause is an `AggregateError` of both. The index stores no body text (pointer-only).
Acceptance: created/updated/unchanged/deleted paths, idempotent replay, partial failure leaves old chunks intact (no half-indexed doc), tenant isolation (same docId in two tenants), ACL change reindexes ACL columns.
