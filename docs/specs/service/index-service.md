# index-service
Goal: apply change events to the index. `createIndexService({registry, index, chunk, embed})` exposes `apply(event)`: upsert pointer; if change=="unchanged" do nothing; if updated/created fetch text via injected `fetchText(pointer)`, chunk it, embed via injected `embed(texts)`, replace the doc's chunks in hybrid-search (remove(docId,tenantId) then add). Deleted event tombstones pointer and removes chunks. Uses @brain/pointer-registry, @brain/chunker, @brain/hybrid-search, @brain/core-types.
Acceptance: created/updated/unchanged/deleted paths, idempotent replay, partial failure leaves old chunks intact (no half-indexed doc), tenant isolation (same docId in two tenants), ACL change reindexes ACL columns.
