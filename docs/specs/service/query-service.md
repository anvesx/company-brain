# query-service
Goal: ACL-safe search. `createQueryService({index, registry})` exposes `search({query, limit, principal, embedding})`: hybrid-search with acl-filter clause for the principal, hydrate pointers from registry, drop tombstoned and cross-tenant pointers, return Pointer[]. Uses @brain/hybrid-search, @brain/acl-filter, @brain/pointer-registry, @brain/core-types.
Acceptance: user/group/zone visibility matrix, tenant isolation, deleted docs hidden, limit bounds, empty query typed error, ACL revoked after index still hidden.
