# connector-runtime
Goal: poll connectors and emit deduped events. `createConnectorRuntime({connector, cursors, sink, clock})` exposes `runOnce(tenantId)`: page through connector-kit list with cursor, for each item emit change event to injected `sink` once (change-cursor seen(tenantId,eventId)), persist cursor only after sink success, resume after crash, BAD_CURSOR restarts full scan. Uses @brain/connector-kit, @brain/change-cursor, @brain/core-types.
Acceptance: first run emits all, second run emits none, modified file emits one, sink failure does not advance cursor, crash-resume, tenant isolation.
Rules: package services/NAME, name @brain/NAME, depends ONLY on @brain/* features + third-party libs (never another service). TDD: write failing tests first under tests/{unit,integration}. Files <=80 lines, folders <=5 files (README exempt), src/ + tests/ + README.md in every package and README in every src subfolder. ESM TypeScript, node:sqlite, vitest 5, zod. Copy package.json/tsconfig/vitest/stryker config shape from features/mcp-search-tool. Inject clock/IO. Typed errors. Run pnpm structure, pnpm exec biome check ., pnpm --filter @brain/NAME test/typecheck before reporting.
