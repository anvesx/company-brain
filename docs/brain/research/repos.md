# Open-source building blocks for a company brain (index, not copy)

Checked 2026-10-23 with `gh` (stars, licence, last push). 56 repos in `repos.json`. Where GitHub reports NOASSERTION the licence is custom or mixed, so read it before shipping.

1. Nobody ships the whole thing. Onyx (`onyx`) and Airweave (`airweave`) come closest, and both keep their own copy of chunk text. Our "index plus live fetch" rule is a design choice we build, not a repo we install.
2. Do not clone a "company brain" repo. The repos that call themselves one (`supermemory-cb`, `scout`, `ankole`, `kombo-cb`, `zilobase`) are small (under about 1,100 stars) and mostly Slack bots or Markdown dumps. `kombo-cb` is explicitly a full copy, so use it only as a counter-example.
3. Install, do not build, the connectors. Airbyte (`airbyte`), Nango (`nango`), Composio (`composio`), Pipedream components (`pipedream`) and the vendor MCP servers (`mcp-servers`, `mcp-registry`, `metorial`) cover hundreds of apps. Check licences: `airbyte`, `nango`, `pipedream`, `metorial` are not plain open source.
4. Use two connector paths. Sync path: webhooks and cursors write only titles, owners, links, ACLs and short summaries (`cocoindex`, `dlt`, `airbyte`). Live path: an MCP tool or `steampipe`-style query fetches the real content at question time. `steampipe` proves live SQL without a stored copy, but is AGPL and rate-limit bound.
5. Put every app behind an MCP gateway (`contextforge`, `agentgateway`, `docker-mcp`) so one place enforces per-user tokens, tool allow-lists and audit. Install it; build only the policy.
6. Core index: start on Postgres with pgvector and pgvectorscale (`pgvector`, `pgvectorscale`) so pointers, ACL rows and vectors join in one query. Move to Vespa (`vespa`) or OpenSearch (`opensearch`, document-level security) when scale or hybrid ranking needs it. Qdrant (`qdrant`) is the light dedicated option.
7. Permissions are the hard part and the part to build. Install OpenFGA or SpiceDB (`openfga`, `spicedb`) for the relation model, and Cerbos or OPA (`cerbos`, `opa`) for policy. No repo syncs Drive, Slack and Jira ACLs into them for you. Build that sync, then pre-filter search by user.
8. Self-updating needs durable jobs. Run backfills, webhook reconciliation and retries on Temporal (`temporal`). Use `debezium` only for company databases, since it does not read SaaS APIs.
9. Agent memory (`mem0`, `letta`, `graphiti`, `cognee`, `supermemory`) is for learned facts and preferences, not documents. Graphiti (`graphiti`) fits best for a map of people, projects and sources with timestamps, but it costs an LLM call per ingest.
10. RAG frameworks (`llamaindex`, `haystack`) are glue, not the product. Full GraphRAG (`graphrag`) is costly to rebuild on change, so prefer incremental graphs (`lightrag`, `graphiti`). `r2r` has had no push since Nov 2025, so skip it.
11. Parsers (`unstructured`, `docling`, `ragflow`) are only needed at fetch or index time and can be swapped freely.
12. Buy or install: connectors, gateway, search engine, authorization engine, workflow engine, parsers. Build: the permission sync, the pointer-and-summary schema, the freshness rules (when to re-fetch), and the answer layer that cites live sources.
