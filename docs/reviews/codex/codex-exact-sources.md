Read-only `codex exec` run against docs/brain/research/exact and docs/brain/model.json. Verdict: HOLD. Finding 7 (metadata bypass) is addressed by widening the key denylist in graph-store. Findings 1 to 6 are open.

4. **High — the graph lacks organizational relationships.** Failure → it cannot answer ownership, membership, mentions or cross-app relationship questions. Cause → graph-sync creates document nodes, one synthetic project root, `belongs-to`, and `can-read`; the HTTP API exposes documents only. Fix → ingest connector-native `authored`, `member-of`, `mentions`, and `links-to` edges, then expose bounded traversal.
