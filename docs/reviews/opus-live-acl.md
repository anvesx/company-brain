# Review: live ACL, offset paging, single fetch, known/reap, signed tokens

Branch `main`, read-only review. All six in-scope suites are green (hybrid-search 56, query-service 75, index-service 71, retrieval 47, ingestion 42, brain-app 68). None of the defects below is caught by those tests.

No finding widens access. The cached ACL (`allowClause` in both index lists plus `isAllowed` against the registry) always runs before the live check. A live verdict can only narrow access, and every non-`allow` verdict is dropped. Only the brain spec requires fail-closed; the defects below are about whether the live ACL works at all, about cost, and about deletes and availability.

## Checked and found correct
- **Fail-closed verdict mapping** (`live.ts:26-32`): only `"allow"` is kept. A missing id, non-Map result, throw or timeout counts as unverified. Timers are cleared.
- **Audit digest:** retrieval's `audited` matches governance's `createTargetDigest` byte for byte (HMAC(HMAC(key, "brain-audit-target-key:"+tenant), trimmed query)). Row shape is the same. `audit.record` then `chain.append` is synchronous, so concurrent async searches cannot fork the chain.
- **Offset paging:** pages are disjoint ranks of one fused order. Chunk and doc dedupe is correct. A short page or a page with no new chunk terminates the scan.
- **Restore ACL:** narrowing never sticks as "unchanged" on replay. `isUnchanged` compares ACL lists as sets, so the narrowed pointer re-applies as `updated`.
- **Single fetch:** the ingestion hash and index-service `verifyContent` both use sha-256 hex of UTF-8 text. `HASH_MISMATCH` fires before any state change.
- **Cursor reset:** connector-runtime resets the cursor to `""` after a complete listing, so `sawEverything()` comes true again on the run after a resumed run.
- **Token compare:** fixed-length hex check plus `timingSafeEqual`. The colon is excluded from user and tenant, so the HMAC message is unambiguous. MCP HTTP binds `127.0.0.1` by default.
- **FTS escaping:** every token is quoted. The ACL fragment is constant SQL with bound params.
