## Low (6)

- L1 graph-store `src/nodes.ts:51-59`: revive dated before the tombstone (upsert at 150 after tombstone at 200) leaves overlapping rows; `node(asOf 170)` gives the old version. Check the last closed row's `valid_to`.
- L2 graph-sync `src/sync.ts:26`: only an identical repeat cursor is caught; `1,2,1,2…` loops forever. Add a page cap.
- L3 graph-sync README:3 says text is never read; folder `list` reads every file in full to hash it (folder-scan.ts:23). Say "never stored"; stream the hash.
- L4 core-types `src/acl.ts:7-8`: ACL arrays are unbounded (Principal groups cap at 1000). Add `.max()`.
- L5 query-router `src/sources.ts:14-15`: naming only unconnected sources gives a retrieval mode with `sources: []`; a caller reading `[]` as "all" over-fetches. Return `none` or state it.
- L6 graph-sync tests import graph-store and connector-kit through `dist`; `pnpm --filter … test` without a build tests stale code (turbo builds first).
