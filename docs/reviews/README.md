# Reviews

Independent reviews of this repo. Reviews are read-only: they record findings with `file:line` and
a verdict, and fixes land in separate commits.

| Folder | What it holds |
| --- | --- |
| [features/](features/README.md) | Opus reviews of the feature packages and graph-sync |
| [codex/](codex/README.md) | Codex reviews |
| [ops/](ops/README.md) | Production, live-ACL, reuse and stub audits |
| [mapping/](mapping/README.md) | Spec mapping and brain-versus-rag gap notes |

Rules: each file is at most 80 lines, a longer review splits into a main file and a `-details`
file, and no folder holds more than 5 files including its README.
