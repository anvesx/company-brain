# views

Pure functions from data to an HTML string.

- `auth.ts`: sign-in and sign-up forms, the Continue with Google button, and the message for a failed Google sign-in (`readQuery`).
- `flow.ts`: organization picker and consent.
- `connections.ts`: the signed-in home. Catalog first when there are no connections, then the install guide.
- `guide.ts`: the install guide for every client, and the copy script.
