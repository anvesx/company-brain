# pages (unit)

- `layout.test.ts`: escaping, the page shell, `field` and `hidden` helpers.
- `auth.test.ts`: sign-in and sign-up pages, alert, OAuth query carry-over.
- `flow.test.ts`: organization picker, consent page, account page.
- `connections.test.ts`: connections page, connector catalog, install guide.
