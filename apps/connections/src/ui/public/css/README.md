# css

Plain stylesheets in the DevX doctrine look: white paper, ink text, hairline rules, sharp corners, no shadows, one blue accent. System fonts only, because the content security policy allows no remote fonts.

- `base.css`: page, type and layout.
- `header.css`: the top bar.
- `cards.css`: connection cards.
- `controls/`: `forms.css` and `buttons.css`, loaded after the cards.
