# views

One function per screen, each takes the root element and renders into it.

- `signin.js`: paste the bearer, checked against `GET /v1/accounts`.
- `list.js`: connection cards with provider and data zone filters.
- `add.js`: the add form for oauth, admin-token and pat.
- `hints.js`: zone choices and the widening rule, in plain words.
- `account/`: one account, change zones, disconnect.
