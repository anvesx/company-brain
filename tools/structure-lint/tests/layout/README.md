# layout

Tests for the folder-shape rules: `layout.test.ts` (package README, src, tests),
`root.test.ts` (at most five files in the package root, configs and dotfiles counted),
`readme.test.ts` (a README in every code folder and the narrow `.json` data-only exemption) and
`beside.test.ts` (tests live in `tests/` beside `src`, stray test files are reported).
